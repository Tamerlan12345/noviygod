# Тайный Санта 3D

Это проект для проведения игры "Тайный Санта" среди 12 участников с 3D-интерфейсом.

## Стек технологий

*   **Frontend:** React (Vite) + Three.js
*   **Backend & БД:** Supabase
*   **Хостинг:** Railway

## Структура проекта

*   `frontend/`: Файлы фронтенда
*   `supabase/`: Файлы для Supabase (миграции, функции)
